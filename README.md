# StudioLiteAssetFinder

StudioLiteAssetFinder is an open-source project designed to help users find asset IDs in the Roblox Studio Lite environment. This tool simplifies the process of searching for assets by providing a straightforward interface to query the Roblox Marketplace API. It is particularly useful for developers and creators who need quick access to asset information without leaving the Studio Lite interface.

## Install

To install StudioLiteAssetFinder, follow these steps:

1. Clone the repository to your local machine using the following command:
   ```sh
   git clone https://github.com/yourusername/StudioLiteAssetFinder.git
   ```
2. Navigate to the project directory:
   ```sh
   cd StudioLiteAssetFinder
   ```
3. Copy the `src/main.lua` file to your Roblox Studio Lite scripts folder.

## Use

To use StudioLiteAssetFinder, follow these steps:

1. Open Roblox Studio Lite.
2. Navigate to the script editor where you copied the `main.lua` file.
3. Modify the example usage line to search for the desired asset:
   ```lua
   searchAssets("your desired asset name")
   ```
4. Run the script. The script will print the Asset ID and Name of the assets matching your search query.
